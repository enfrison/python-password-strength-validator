# Python Password Strength Validator

A Python program that evaluates user-entered passwords against defined security requirements and identifies which requirements have not been met.

## Features

- Accepts a password from the user
- Checks for lowercase letters
- Checks for uppercase letters
- Checks for required special characters
- Verifies that the password meets the minimum length requirement
- Provides feedback when password requirements are not satisfied

## Technical Concepts Demonstrated

- Python
- Regular Expressions (`re`)
- Functions
- Conditional Logic
- String Validation
- User Input
- Boolean Conditions

## How It Works

The program uses a `passwordStrength` function to evaluate a password against multiple requirements.

Regular expressions are used to determine whether the password contains required character types, including uppercase letters, lowercase letters, and special characters. The program also checks the length of the password to ensure it contains at least eight characters.

If a requirement is not met, the program provides feedback identifying the missing password requirement.

## Purpose

This project was developed to practice Python programming while applying functions, regular expressions, conditional statements, and input validation to a password security scenario.
